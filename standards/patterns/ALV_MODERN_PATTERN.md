# ALV 리팩토링 코드 패턴 Quick Reference

> **표준 위치/역할**: S/4 모던 ALV **코드 패턴 라이브러리(복붙 스켈레톤)**. ALV 리팩토링의 **To-Be 방향 SSOT**.
> 리뷰 기준·판단 원칙은 [`../CBO_REVIEW_GUIDE.md`](../CBO_REVIEW_GUIDE.md), 표준 우선순위는 [`../README.md`](../README.md) 참조.
>
> ZMMPAR52000(수불부) 리팩토링에서 확립된 코드 패턴 모음.
> 새 프로그램 리팩토링 시 복사하여 사용한다.
>
> **핵심 방향**: 5벌(_100~500) → 2벌(MAIN 풀스크린 / POP 팝업) · `NEW`+메서드체이닝 · RTTI 필드카탈로그 · 단일 이벤트클래스(SENDER 분기) · 컨트롤 생명주기 철칙.

## 1. TOP 선언 템플릿

```abap
*----------------------------------------------------------------------*
* ALV - Event Handler Class (forward declaration)

CLASS LCL_EVENT_RECEIVER DEFINITION DEFERRED.
DATA : GCL_EVENT TYPE REF TO LCL_EVENT_RECEIVER.

*----------------------------------------------------------------------*
* ALV - 풀스크린 (메인)
*----------------------------------------------------------------------*
DATA : GCL_GRID_MAIN     TYPE REF TO CL_GUI_ALV_GRID,

*----------------------------------------------------------------------*
* ALV - 팝업 스크린
*----------------------------------------------------------------------*

       GT_FIELDCAT_POP    TYPE LVC_T_FCAT,
       GS_LAYOUT_POP      TYPE LVC_S_LAYO,
       GT_EXCLUDE_POP     TYPE UI_FUNCTIONS,
       GT_SORT_POP        TYPE LVC_T_SORT,
       GS_VARIANT_POP     TYPE DISVARIANT,
       GCL_DOCKING_POP    TYPE REF TO CL_GUI_DOCKING_CONTAINER,   " 팝업용
       GCL_TOP_CONT_POP   TYPE REF TO CL_GUI_CONTAINER.

*----------------------------------------------------------------------*
* ALV - 공통 (TOP_OF_PAGE)
*----------------------------------------------------------------------*
```

## 2. CLS 이벤트 클래스 템플릿

```abap
CLASS LCL_EVENT_RECEIVER DEFINITION.
  PUBLIC SECTION.
    METHODS : HANDLE_DOUBLE_CLICK
      FOR EVENT DOUBLE_CLICK OF CL_GUI_ALV_GRID
      IMPORTING E_ROW E_COLUMN SENDER.
    METHODS : HANDLE_HOTSPOT_CLICK
      FOR EVENT HOTSPOT_CLICK OF CL_GUI_ALV_GRID
      IMPORTING E_ROW_ID E_COLUMN_ID SENDER.
    METHODS : HANDLE_TOOLBAR
      FOR EVENT TOOLBAR OF CL_GUI_ALV_GRID
      IMPORTING E_OBJECT E_INTERACTIVE SENDER.
    METHODS : HANDLE_USER_COMMAND
      FOR EVENT USER_COMMAND OF CL_GUI_ALV_GRID
      IMPORTING E_UCOMM SENDER.
    METHODS : ON_TOP_OF_PAGE
      FOR EVENT TOP_OF_PAGE OF CL_GUI_ALV_GRID
      IMPORTING E_DYNDOC_ID.
ENDCLASS.

CLASS LCL_EVENT_RECEIVER IMPLEMENTATION.
  METHOD HANDLE_DOUBLE_CLICK.
    CASE SENDER.
      WHEN GCL_GRID_MAIN. PERFORM HANDLE_DBLCLICK_MAIN USING E_ROW E_COLUMN.
      WHEN GCL_GRID_POP.  PERFORM HANDLE_DBLCLICK_POP  USING E_ROW E_COLUMN.
    ENDCASE.
  ENDMETHOD.
  METHOD HANDLE_HOTSPOT_CLICK.
    CASE SENDER.
      WHEN GCL_GRID_MAIN. PERFORM HANDLE_DBLCLICK_MAIN USING E_ROW_ID E_COLUMN_ID.
    ENDCASE.
  ENDMETHOD.
  METHOD HANDLE_TOOLBAR.
    CASE SENDER.
      WHEN GCL_GRID_MAIN. PERFORM HANDLER_TOOLBAR_MAIN USING E_OBJECT SENDER.
    ENDCASE.
  ENDMETHOD.
  METHOD HANDLE_USER_COMMAND.
    CASE SENDER.
      WHEN GCL_GRID_MAIN. PERFORM HANDLE_UCOMM_MAIN USING E_UCOMM SENDER.
    ENDCASE.
  ENDMETHOD.
  METHOD ON_TOP_OF_PAGE.
    PERFORM TOP_OF_PAGE USING E_DYNDOC_ID.
  ENDMETHOD.
ENDCLASS.
```

## 3. 인스턴스 생성 패턴

### 3-1. 풀스크린 (SCREEN0)

```abap
FORM CREATE_INSTANCE_MAIN.
  GCL_SPLITTER_MAIN = NEW CL_GUI_SPLITTER_CONTAINER(
    PARENT  = CL_GUI_CONTAINER=>SCREEN0
    ROWS    = 2
    COLUMNS = 1 ).
  GCL_SPLITTER_MAIN->SET_ROW_MODE(
    MODE = CL_GUI_SPLITTER_CONTAINER=>MODE_RELATIVE ).
  GCL_SPLITTER_MAIN->SET_ROW_HEIGHT( ID = 1  HEIGHT = 10 ).
  GCL_TOP_CONT_MAIN = GCL_SPLITTER_MAIN->GET_CONTAINER( ROW = 1 COLUMN = 1 ).
  DATA(LCL_GRID_CONT) = GCL_SPLITTER_MAIN->GET_CONTAINER( ROW = 2 COLUMN = 1 ).
  GCL_GRID_MAIN = NEW CL_GUI_ALV_GRID( I_PARENT = LCL_GRID_CONT ).
ENDFORM.
```

### 3-2. 팝업 (Docking Container)

```abap
FORM CREATE_INSTANCE_POP.
  GCL_DOCKING_POP = NEW CL_GUI_DOCKING_CONTAINER(
    DYNNR     = SY-DYNNR
    REPID     = SY-REPID
    SIDE      = CL_GUI_DOCKING_CONTAINER=>DOCK_AT_TOP
    EXTENSION = 1500 ).
  DATA(LCL_SPLIT) = NEW CL_GUI_SPLITTER_CONTAINER(
    PARENT  = GCL_DOCKING_POP
    ROWS    = 2
    COLUMNS = 1 ).
  LCL_SPLIT->SET_ROW_MODE(
    MODE = CL_GUI_SPLITTER_CONTAINER=>MODE_RELATIVE ).
  LCL_SPLIT->SET_ROW_HEIGHT( ID = 1  HEIGHT = 20 ).
  GCL_TOP_CONT_POP = LCL_SPLIT->GET_CONTAINER( ROW = 1 COLUMN = 1 ).
  DATA(LCL_GRID_CONT) = LCL_SPLIT->GET_CONTAINER( ROW = 2 COLUMN = 1 ).
  GCL_GRID_POP = NEW CL_GUI_ALV_GRID( I_PARENT = LCL_GRID_CONT ).
ENDFORM.
```

## 4. 필드카탈로그 패턴

```abap
DEFINE _LMC_SET_TEXT.
  <LS_FCAT>-SCRTEXT_S = <LS_FCAT>-SCRTEXT_M = <LS_FCAT>-TOOLTIP =
  <LS_FCAT>-SCRTEXT_L = <LS_FCAT>-COLTEXT = <LS_FCAT>-REPTEXT = &1.
END-OF-DEFINITION.

FORM SET_FIELDCAT_MAIN.
  CLEAR GT_FIELDCAT_MAIN.

  " CL_SALV_DATA_DESCR로 자동 생성
  GT_FIELDCAT_MAIN = CORRESPONDING #(
    CL_SALV_DATA_DESCR=>READ_STRUCTDESCR(
      CAST CL_ABAP_STRUCTDESCR(
        CAST CL_ABAP_TABLEDESCR(
          CL_ABAP_STRUCTDESCR=>DESCRIBE_BY_DATA( GT_LIST )
        )->GET_TABLE_LINE_TYPE( ) ) ) ).

  " 필드별 커스터마이징
  LOOP AT GT_FIELDCAT_MAIN ASSIGNING FIELD-SYMBOL(<LS_FCAT>).
    CLEAR <LS_FCAT>-KEY.
    CASE <LS_FCAT>-FIELDNAME.

      WHEN 'BUKRS'.
        <LS_FCAT>-COL_POS = 1. <LS_FCAT>-KEY = ABAP_TRUE.
        _LMC_SET_TEXT TEXT-F01.

      WHEN 'MENGE'.
        <LS_FCAT>-COL_POS = 10.
        <LS_FCAT>-QFIELDNAME = 'MEINS'.   " ← 수량 참조 필수
        <LS_FCAT>-DO_SUM = ABAP_TRUE.
        _LMC_SET_TEXT TEXT-F02.

      WHEN 'DMBTR'.
        <LS_FCAT>-COL_POS = 11.
        <LS_FCAT>-CFIELDNAME = 'WAERS'.   " ← 통화 참조 필수 (KRW 환산)
        <LS_FCAT>-DO_SUM = ABAP_TRUE.
        _LMC_SET_TEXT TEXT-F03.

      WHEN 'CELLTAB' OR 'COLINFO' OR 'INFO' OR 'MARK'.
        <LS_FCAT>-NO_OUT = ABAP_TRUE.

      WHEN OTHERS.
        <LS_FCAT>-COL_POS = 990. <LS_FCAT>-NO_OUT = ABAP_TRUE.

    ENDCASE.
  ENDLOOP.

  DELETE GT_FIELDCAT_MAIN WHERE COL_POS = 990.
ENDFORM.
```

## 5. 컨트롤 해제 패턴

### 5-1. 팝업 해제 (호출 직전)

```abap
FORM FREE_POPUP_CONTROLS USING PV_SCREEN TYPE SY-DYNNR.

  CLEAR GCL_HTML_VIEWER.    " ⚠️ FREE 금지, CLEAR만

  CASE PV_SCREEN.
    WHEN '0200'.
      IF GCL_GRID_POP IS BOUND.
        GCL_GRID_POP->FREE( ). CLEAR GCL_GRID_POP.
      ENDIF.
      IF GCL_DOCKING_POP IS BOUND.
        GCL_DOCKING_POP->FREE( ). CLEAR GCL_DOCKING_POP.
      ENDIF.
      CLEAR GCL_TOP_CONT_POP.
  ENDCASE.

  CL_GUI_CFW=>FLUSH( ).

ENDFORM.
```

### 5-2. 호출부

```abap
" 팝업 열기 직전에 기존 컨트롤 해제
PERFORM FREE_POPUP_CONTROLS USING '0200'.
CALL SCREEN 0200 STARTING AT 10 2 ENDING AT 150 30.
```

### 5-3. EXIT_RTN

```abap
FORM EXIT_RTN.
  CLEAR GCL_HTML_VIEWER.    " 공통: FREE 금지

  CASE SY-DYNNR.
    WHEN '0400'.             " 풀스크린만 직접 FREE
      IF GCL_GRID_MAIN IS BOUND.
        GCL_GRID_MAIN->FREE( ). CLEAR GCL_GRID_MAIN.
      ENDIF.
      IF GCL_SPLITTER_MAIN IS BOUND.
        GCL_SPLITTER_MAIN->FREE( ). CLEAR GCL_SPLITTER_MAIN.
      ENDIF.
      CLEAR GCL_TOP_CONT_MAIN.
      CL_GUI_CFW=>FLUSH( ).
      LEAVE TO SCREEN 0.

    WHEN OTHERS.              " 팝업은 LEAVE만
      LEAVE TO SCREEN 0.
  ENDCASE.
ENDFORM.
```

## 6. 이벤트 등록 공통화 패턴

```abap
FORM CREATE_EVENT_RECEIVER USING PO_GRID TYPE REF TO CL_GUI_ALV_GRID.
  IF GCL_EVENT IS NOT BOUND.
    CREATE OBJECT GCL_EVENT.
  ENDIF.
  PO_GRID->REGISTER_EDIT_EVENT(
    EXPORTING I_EVENT_ID = CL_GUI_ALV_GRID=>MC_EVT_MODIFIED ).
  PO_GRID->REGISTER_EDIT_EVENT(
    EXPORTING I_EVENT_ID = CL_GUI_ALV_GRID=>MC_EVT_ENTER ).
  SET HANDLER GCL_EVENT->HANDLE_DOUBLE_CLICK  FOR PO_GRID.
  SET HANDLER GCL_EVENT->HANDLE_HOTSPOT_CLICK FOR PO_GRID.
  SET HANDLER GCL_EVENT->HANDLE_TOOLBAR       FOR PO_GRID.
  SET HANDLER GCL_EVENT->HANDLE_USER_COMMAND  FOR PO_GRID.
  SET HANDLER GCL_EVENT->ON_TOP_OF_PAGE       FOR PO_GRID.
ENDFORM.
```

## 7. Display ALV 패턴

```abap
FORM DISPLAY_ALV_MAIN.
  GS_VARIANT_MAIN-REPORT = SY-REPID.

  GCL_ALV_DOCUMENT = NEW CL_DD_DOCUMENT( STYLE = 'ALV_GRID' ).
  GCL_ALV_DOCUMENT->INITIALIZE_DOCUMENT( ).
  GCL_GRID_MAIN->LIST_PROCESSING_EVENTS(
    EXPORTING I_EVENT_NAME = 'TOP_OF_PAGE'
              I_DYNDOC_ID  = GCL_ALV_DOCUMENT ).

  GCL_GRID_MAIN->SET_TABLE_FOR_FIRST_DISPLAY(
    EXPORTING IS_LAYOUT            = GS_LAYOUT_MAIN
              IS_VARIANT           = GS_VARIANT_MAIN
              IT_TOOLBAR_EXCLUDING = GT_EXCLUDE_MAIN
              I_SAVE               = 'A'
    CHANGING  IT_OUTTAB            = GT_LIST
              IT_FIELDCATALOG      = GT_FIELDCAT_MAIN
              IT_SORT              = GT_SORT_MAIN ).
ENDFORM.
```

## 8. HTML TOP_OF_PAGE 패턴

```abap
FORM HTML_DISPLAY.
  " 현재 스크린의 TOP 컨테이너 결정
  DATA LCL_TOP TYPE REF TO CL_GUI_CONTAINER.
  CASE SY-DYNNR.
    WHEN '0400'. LCL_TOP = GCL_TOP_CONT_MAIN.
    WHEN '0200'. LCL_TOP = GCL_TOP_CONT_POP.
  ENDCASE.

  CHECK LCL_TOP IS BOUND.

  CLEAR GCL_HTML_VIEWER.   " ⚠️ FREE 금지
  GCL_HTML_VIEWER = NEW CL_GUI_HTML_VIEWER( PARENT = LCL_TOP ).

  CALL FUNCTION 'REUSE_ALV_GRID_COMMENTARY_SET'
    EXPORTING DOCUMENT = GCL_ALV_DOCUMENT  BOTTOM = SPACE.

  GCL_ALV_DOCUMENT->MERGE_DOCUMENT( ).
  GCL_ALV_DOCUMENT->SET_DOCUMENT_BACKGROUND(
    PICTURE_ID = CONV SDYDO_KEY( SPACE ) ).
  GCL_ALV_DOCUMENT->HTML_CONTROL = GCL_HTML_VIEWER.
  GCL_ALV_DOCUMENT->DISPLAY_DOCUMENT(
    EXPORTING REUSE_CONTROL = 'X'  PARENT = LCL_TOP ).
ENDFORM.
```
